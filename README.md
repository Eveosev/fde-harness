# FDE Harness

FDE Harness 面向在客户现场交付数据与工程任务的工程师。项目关注宿主 Agent 如何接入多源数据、核实业务口径，并通过工作记录让另一位经办人接手续办。

当前处于设计阶段。

## 阅读入口

- 了解交付目标、范围和验收条件，读[产品需求](docs/fdeharness/01-product-requirements.md)。
- 查宿主、Harness 和执行器的分工，读[架构设计](docs/fdeharness/02-architecture.md)。
- 比较两种交互方式，读[方案 A · 静态产物](docs/fdeharness/03-ui-static.md)和[方案 B · 本地工作台](docs/fdeharness/04-ui-workbench.md)。
